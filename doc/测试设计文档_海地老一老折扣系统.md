# 海地老一老折扣系统 - 黑盒测试设计文档

## 一、系统需求分析

### 1.1 业务规则
1. **用户身份限制**：只有大学生可以领取和使用折扣券，如果学生有折扣券，必须使用
2. **12%折扣（88折）**：全天可用，仅限大学生
3. **31%折扣（69折）**：仅限大学生，特定时间段可用
   - 周一到周五：14:00（含）-17:00，22:00（含）-次日07:00
   - 周六和周日：00:00（含）-07:00
   - 时间区间包含起始时间，不包含结束时间
   - 如果满足31%折扣的所有条件，必须优先于12%折扣
4. **折扣上限**：单笔账单最大折扣金额上限为￥1000
5. **消费金额范围**：￥10.00 到 ￥10000.00（有效范围）

### 1.2 输入输出
- **输入**：[星期几, 结账时间, 消费金额, 是否大学生(Y/N), 是否有12%折扣(Y/N), 是否有31%折扣(Y/N)]
- **输出**：最终支付金额(￥) 或 错误信息（如果消费金额无效）

## 二、因果图（Cause-Effect Graph）（10分）

### 2.1 Causes
- C1: Is College Student (IsCollegeStudent = Y)
- C2: Is Not College Student (IsCollegeStudent = N)
- C3: Has 12% Off Discount Coupon (Has12Off = Y)
- C4: Does Not Have 12% Off Discount Coupon (Has12Off = N)
- C5: Has 31% Off Discount Coupon (Has31Off = Y)
- C6: Does Not Have 31% Off Discount Coupon (Has31Off = N)
- C7: Within 31% Off Valid Time Period
- C8: Not Within 31% Off Valid Time Period
- C9: Consumption Amount Within Valid Range (10.00 ≤ amount ≤ 10000.00)
- C10: Consumption Amount Invalid (amount < 10.00 or amount > 10000.00)

### 2.2 Effects
- E1: Apply 31% Off Discount
- E2: Apply 12% Off Discount
- E3: No Discount Applied (Pay Original Price)
- E4: Return Error Message

1. **E1 (Apply 31% Off Discount)**: C1 ∧ C5 ∧ C7 ∧ C9

3. **E3 (No Discount Applied)**: C2 ∧ C9 or C1 ∧ ¬C3 ∧ ¬C5 ∧ C9
4. **E4 (Return Error)**: C10

## 五、边界值分析（Boundary Value Analysis）（30分）

### 5.1 边界值识别

#### 5.1.1 消费金额边界值
- **下边界**：9.99, 10.00, 10.01
- **上边界**：9999.99, 10000.00, 10000.01

#### 5.1.2 时间边界值（31%折扣时间段）

**周一到周五 14:00-17:00**
- 起始边界：13:59, 14:00, 14:01
- 结束边界：16:59, 17:00, 17:01

**周一到周五 22:00-次日07:00**
- 起始边界：21:59, 22:00, 22:01
- 结束边界：06:59, 07:00, 07:01

**周六和周日 00:00-07:00**
- 起始边界：23:59（前一天）, 00:00, 00:01
- 结束边界：06:59, 07:00, 07:01

#### 5.1.3 折扣金额上限边界值
- 当原价为￥3225.81时，31%折扣 = ￥1000.00（正好达到上限）
- 当原价为￥3225.80时，31%折扣 = ￥999.80（略低于上限）
- 当原价为￥3225.82时，31%折扣 = ￥1000.01（略高于上限，应限制为￥1000）

计算：设原价为X，折扣金额 = X × 0.31
当 X × 0.31 = 1000 时，X = 1000 / 0.31 ≈ 3225.81

### 7.1 折扣计算规则
1. **31%折扣计算**：
   - 折扣金额 = 原价 × 0.31
   - 如果折扣金额 > 1000，则折扣金额 = 1000
   - 最终支付 = 原价 - 折扣金额

2. **12%折扣计算**：
   - 折扣金额 = 原价 × 0.12
   - 如果折扣金额 > 1000，则折扣金额 = 1000
   - 最终支付 = 原价 - 折扣金额

3. **折扣优先级**：
   - 如果同时满足31%折扣条件，优先使用31%折扣
   - 否则，如果满足12%折扣条件，使用12%折扣
   - 否则，不应用折扣
