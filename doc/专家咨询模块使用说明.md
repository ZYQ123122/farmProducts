# 专家咨询模块使用说明

## 一、模块概述

专家咨询模块是一个完整的咨询管理系统，支持用户向专家发起咨询，专家进行回复的功能。

## 二、已创建的文件

### 1. 后端文件

#### 实体类
- `ruoyi-system/src/main/java/com/ruoyi/system/domain/ExpertConsultation.java`
  - 专家咨询实体类，包含咨询ID、用户ID、专家ID、标题、内容、状态、回复等字段

#### 数据访问层
- `ruoyi-system/src/main/java/com/ruoyi/system/mapper/ExpertConsultationMapper.java`
  - Mapper接口，定义数据操作方法
- `ruoyi-system/src/main/resources/mapper/system/ExpertConsultationMapper.xml`
  - MyBatis映射文件，实现SQL查询

#### 业务逻辑层
- `ruoyi-system/src/main/java/com/ruoyi/system/service/IExpertConsultationService.java`
  - Service接口
- `ruoyi-system/src/main/java/com/ruoyi/system/service/impl/ExpertConsultationServiceImpl.java`
  - Service实现类

#### 控制器层
- `ruoyi-admin/src/main/java/com/ruoyi/web/controller/system/ExpertConsultationController.java`
  - RESTful API控制器

### 3. 数据库文件

- `sql/expert_consultation.sql`
  - 专家咨询表创建脚本

  - 菜单配置SQL脚本

## 三、安装步骤

### 1. 创建数据库表

执行SQL脚本创建专家咨询表：

```sql
-- 执行文件：sql/expert_consultation.sql
source sql/expert_consultation.sql;
```

或者在MySQL客户端中直接执行 `sql/expert_consultation.sql` 文件。

### 2. 配置菜单权限

执行菜单配置SQL脚本：

```sql
-- 执行文件：sql/expert_consultation_menu.sql
source sql/expert_consultation_menu.sql;
```

或者在MySQL客户端中直接执行 `sql/expert_consultation_menu.sql` 文件。

### 3. 分配菜单权限

1. 登录系统（http://localhost）
2. 进入 **系统管理** -> **角色管理**
3. 选择需要分配权限的角色（如：管理员）
4. 点击 **修改** -> **菜单权限**
5. 勾选 **专家咨询** 菜单及其所有子菜单
6. 保存

## 四、功能说明

### 1. 咨询管理

- **列表查询**：支持按标题、状态、创建者等条件查询
- **新增咨询**：用户可以创建新的咨询
- **编辑咨询**：用户可以修改自己的咨询（仅限未回复状态）
- **删除咨询**：用户可以删除自己的咨询
- **查看详情**：查看咨询的完整信息和专家回复

### 2. 专家回复

- **回复咨询**：专家可以对分配给自己的咨询进行回复
- **回复后状态自动更新**：回复后咨询状态自动变为"已回复"

### 3. 咨询状态

- **pending（待回复）**：咨询已创建，等待专家回复
- **answered（已回复）**：专家已回复咨询
- **closed（已关闭）**：咨询已关闭

## 五、API接口说明

### 1. 查询咨询列表
- **URL**: `/system/consultation/list`
- **方法**: POST
- **权限**: `system:consultation:list`

### 2. 新增咨询
- **URL**: `/system/consultation/add`
- **方法**: POST
- **权限**: `system:consultation:add`

### 3. 修改咨询
- **URL**: `/system/consultation/edit`
- **方法**: POST
- **权限**: `system:consultation:edit`

### 4. 删除咨询
- **URL**: `/system/consultation/remove`
- **方法**: POST
- **权限**: `system:consultation:remove`

### 5. 回复咨询
- **URL**: `/system/consultation/reply`
- **方法**: POST
- **权限**: `system:consultation:reply`

### 6. 查看详情
- **URL**: `/system/consultation/detail/{id}`
- **方法**: GET

## 六、注意事项

1. **权限控制**：
   - 用户只能修改/删除自己的咨询
   - 专家只能回复分配给自己的咨询
   - 已关闭的咨询无法回复

2. **数据验证**：
   - 咨询标题：必填，最大长度200字符
   - 咨询内容：必填，最大长度2000字符
   - 回复内容：必填

3. **软删除**：
   - 删除操作使用软删除，不会物理删除数据
   - 通过 `is_deleted` 字段标记删除状态

## 七、访问路径

- **列表页面**: http://localhost/system/consultation
- **新增页面**: http://localhost/system/consultation/add
- **编辑页面**: http://localhost/system/consultation/edit/{id}
- **详情页面**: http://localhost/system/consultation/detail/{id}
- **回复页面**: http://localhost/system/consultation/reply?id={id}
