# 银行贷款系统使用说明

## 一、系统概述

本系统实现了真实的银行贷款场景，包括：
- 银行账号登录系统
- 银行发布和管理贷款产品
- 农户选择银行产品并提交贷款申请
- 上传抵押物照片/文件
- 银行审批申请并发送通知

## 二、数据库初始化

### 1. 执行SQL脚本

按以下顺序执行SQL脚本：

```sql
-- 1. 创建银行相关表
source sql/init_bank_tables.sql;

-- 2. 如果finance_application表已存在，执行以下ALTER语句
ALTER TABLE finance_application ADD COLUMN product_id bigint(20) COMMENT '选择的贷款产品ID' AFTER farmer_id;
ALTER TABLE finance_application ADD COLUMN reviewer_id bigint(20) COMMENT '审批银行用户ID' AFTER status;
ALTER TABLE finance_application MODIFY COLUMN bank_id bigint(20) COMMENT '银行ID（产品所属银行）';
ALTER TABLE finance_application ADD KEY idx_finance_product (product_id);
```

### 2. 创建银行账号

1. 在系统用户管理中创建银行用户账号
2. 在`bank_info`表中插入银行信息，关联用户ID：

```sql
INSERT INTO bank_info (bank_code, bank_name, user_id, contact_person, contact_phone, status) 
VALUES ('BANK001', '中国农业银行', 用户ID, '联系人', '联系电话', '0');
```

## 三、功能使用

### 银行端功能

#### 1. 登录系统
- 使用银行分配的账号和密码登录
- 登录后进入银行管理界面

#### 2. 贷款产品管理
- 路径：产品管理 → 贷款产品管理
- 功能：
  - 新增产品：填写产品名称、金额范围、期限、利率等信息
  - 编辑产品：修改产品信息
  - 上架/下架：控制产品是否对农户可见
  - 删除产品：删除不需要的产品

#### 3. 融资申请审批
- 路径：融资管理 → 融资申请列表
- 功能：
  - 查看所有提交的融资申请
  - 查看申请详情（包括选择的产品、金额、抵押物等）
  - 审批申请（通过/拒绝）
  - 填写审批意见

### 农户端功能

#### 1. 查看贷款产品
- 在融资申请页面，系统自动加载所有上架的贷款产品
- 选择产品后，自动显示产品详细信息（利率、额度、期限等）

#### 2. 提交融资申请
- 路径：融资管理 → 融资申请
- 步骤：
  1. 选择贷款产品
  2. 填写申请金额（需在产品范围内）
  3. 填写贷款期限（需在产品范围内）
  4. 填写贷款用途
  5. 填写抵押物说明
  6. 上传抵押物照片或证明文件
  7. 提交申请

#### 3. 查看申请记录
- 路径：融资管理 → 融资记录
- 查看自己提交的所有申请及状态

#### 4. 接收审批通知
- 路径：融资管理 → 通知中心
- 功能：
  - 查看所有通知（包括提交通知和审批结果通知）
  - 标记为已读
  - 查看审批结果和意见

## 四、数据流程

1. **银行发布产品**
   - 银行登录 → 产品管理 → 新增产品 → 上架

2. **农户申请贷款**
   - 农户登录 → 融资申请 → 选择产品 → 填写信息 → 上传文件 → 提交

3. **银行审批**
   - 银行登录 → 融资申请列表 → 查看详情 → 审批（通过/拒绝）→ 填写意见

4. **农户接收通知**
   - 系统自动发送通知 → 农户查看通知中心 → 了解审批结果

## 五、注意事项

1. **银行账号设置**
   - 必须先在`sys_user`表中创建用户
   - 然后在`bank_info`表中关联用户ID
   - 银行用户登录后只能管理自己银行的产品

2. **产品状态**
   - 只有状态为"上架"的产品才会在农户端显示
   - 下架的产品不会影响已提交的申请

3. **文件上传**
   - 支持上传多张照片或文件
   - 文件大小限制由系统配置决定

4. **通知系统**
   - 提交申请时自动发送提交通知
   - 审批完成后自动发送审批结果通知
   - 通知支持标记已读功能

## 六、API接口说明

### 农户端接口
- `GET /system/bank/product/available` - 获取可用产品列表
- `POST /system/finance/apply` - 提交融资申请
- `POST /system/finance/myList` - 查看我的申请列表
- `POST /system/notification/list` - 查看通知列表
- `GET /system/notification/unreadCount` - 获取未读通知数量

### 银行端接口
- `POST /system/bank/product/list` - 查询产品列表
- `POST /system/bank/product/add` - 新增产品
- `POST /system/bank/product/edit` - 编辑产品
- `POST /system/bank/product/remove` - 删除产品
- `POST /system/finance/list` - 查询融资申请列表
- `GET /system/finance/detail` - 查看申请详情
- `POST /system/finance/review` - 审批申请

## 七、常见问题

1. **农户看不到产品？**
   - 检查产品状态是否为"上架"
   - 检查银行状态是否为"正常"

2. **审批后农户没收到通知？**
   - 检查通知表是否正确插入
   - 检查农户用户ID是否正确

3. **文件上传失败？**
   - 检查文件大小是否超限
   - 检查上传路径配置是否正确
